# 🍀 项目介绍与背景

## 项目概述

**Getjobs (工作无忧)** 是一个专为打工人打造的现代化开源全平台自动化求职脚本与管理系统。基于 **Spring Boot + Next.js + Playwright** 技术栈构建，通过结合 AI 大模型的能力，帮助求职者从繁重、重复的海投劳动中解放出来。

```
┌──────────────────────────────────────────┐
│ 前端层（Front） - Next.js, port=6680     │
│  - 任务创建、投递监控、配置管理界面      │
└──────────────────────────────────────────┘
                 │ HTTP / SSE
                 ▼
┌──────────────────────────────────────────┐
│ 后端层（API） - Spring Boot 3.5.7, port=8888 │
│  - 任务调度、数据库访问、状态推送        │
│  - 整合 Worker 模块执行自动化逻辑        │
│  - 提供 REST / SSE 接口供前端使用        │
└──────────────────────────────────────────┘
                 │ 内部模块调用
                 ▼
┌──────────────────────────────────────────┐
│ 执行层（Worker） - Java + Playwright     │
│  - 负责自动登录、岗位抓取、智能投递      │
│  - 每个平台封装为独立模块（boss、51等） │
│  - 提供 Runner 接口供 Spring 调度        │
└──────────────────────────────────────────┘
```

---

## 核心特性

- **🖥️ 现代化图形界面**：提供直观易用的 Web 控制面板，配置关键词、筛选条件与投递日志一目了然。
- **🤖 AI 智能打招呼**：接入兼容 OpenAI 接口协议的大模型，根据你的个人简历信息和 HR 发布的岗位 JD 动态撰写定制化高情商打招呼语。
- **📷 自动附送图片简历**：支持在 Boss直聘打招呼后自动推送图片简历（`resume.jpg`），减少等待 HR 索要简历的中间周期。
- **🛡️ 智能过滤与黑名单**：自动跳过 **不活跃 HR**、**猎头/中介岗位**，支持自定义薪资区间；沟通不适的企业自动加入 SQLite 黑名单，避免重复投递。
- **📱 实时企业微信推送**：通过企业微信 Webhook 实时接收投递进展汇报与每日统计。
- **🔄 超长免登录状态**：支持持久化 Cookie 存储，大部分平台每周仅需扫码一次。

## 支持的求职平台

| 招聘平台 | 自动化状态 | 维护说明 | 推荐度 |
| :--- | :---: | :--- | :---: |
| **Boss直聘** | 🟢 正常运行 | 每日打招呼上限已升至 150 次；支持 AI 智能打招呼与图片简历推送 | ⭐⭐⭐⭐⭐ |
| **猎聘** | 🟢 正常运行 | 支持自动打招呼（建议在猎聘 App 设置自定义打招呼语），量大可用 | ⭐⭐⭐⭐ |
| **智联招聘** | 🟡 基础支持 | 平台限制较多，需要指定默认在线/附件简历 | ⭐⭐ |
| **前程无忧 (51job)** | 🟡 基础支持 | 搜索活人岗位较少，有投递频控机制 | ⭐⭐ |
| **拉勾网** | ⚪ 暂停维护 | 使用人数较少，欢迎社区贡献 PR | ⭐ |

::: warning ⚠️ 平台投递建议
目前核心维护与推荐使用的平台为 **Boss直聘** 与 **猎聘**。建议在 PC 端使用本项目作为兜底和批量过滤工具，对于极度心仪的核心岗位，配合手机端深入沟通效果更佳。
:::
